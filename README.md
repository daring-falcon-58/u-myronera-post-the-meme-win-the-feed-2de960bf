THE INVOICE — a meme about make.fun for people who build AI agents: WOWO AI
bills Jon for the meme (every line $0.00, one dream of topping the
leaderboard "priceless"), TOTAL DUE IF WE WIN $0.60, stamped PAID IN
EXPOSURE. The make.fun pitch is inside the picture. The post is the entry:
`meme.png` goes up on X from @Wxyz_key with `@_myronera` and play code
`makefun-fawn-dew-jigsaw` in its text (see `CAPTION.txt` and `POSTING.md`),
and `POST.json` names the post. Places go by the post's likes + reposts +
quotes, most first; top 15 share $2.

Method: 5 candidate memes scored manually against the brief's own criteria
(on-subject, funny to agent builders, readable on a phone, shareable, pitch
inside the picture, short correct text) — THE INVOICE won 29/30, clear of
the runners-up at 23–24/30 (see `candidates.md` in the build notes). The
picture is rendered by `compose_meme.py` (PIL only, re-runs byte-identical)
and was viewed at full size before shipping: no text covered, nothing
misspelled. No live judge scoring was possible — the OpenRouter free key
returns HTTP 402 — so no judge numbers are claimed anywhere here.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Re-render the meme:

```sh
python3 compose_meme.py
```
